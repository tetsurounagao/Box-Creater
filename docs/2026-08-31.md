## 今日やったこと

### 1. アプリの基礎構築
- **左ペイン: 十字（クルス）展開図エディタ**
  - 天板・底板・前面・背面・左右側面の 6 パネル ＋ 折り線付きフラップを SVG で描画
  - 寸法 W/D/H をドラッグハンドル・数値入力（mm、±ボタン、矢印キー）の両方で変更、対の面が自動追従
  - パネルをクリック → 画像アップロード → 面のアスペクト比に固定したトリミングモーダル（元画像 px 表示、ズーム）
- **右ペイン: 3D プレビュー**
  - `meshPhysicalMaterial`（clearcoat + sheen）＋ ローカル `Lightformer` 環境光で紙のツヤ
  - `CameraControls` でドラッグ回転、面ボタンで `setLookAt` による正面ビュー遷移
- **状態管理**: `zustand`（`boxStore`）。切り抜き済み canvas を派生させて SVG と 3D テクスチャの両方へ供給（`useFaceCanvases`）
- 実装中に修正したバグ:
  - SVG `<image>` がパネル矩形の CSS `fill` に隠れて表示されない → `.net-panel__rect--has-image { fill: transparent }`
  - ドラッグハンドルの `pointerup` 取りこぼしで寸法が発振 → `e.buttons` ガード ＋ `onLostPointerCapture`
  - `Environment preset` の外部 HDR 依存で 3D が描画されない → ローカル `Lightformer` に置換、`frameloop` 明示
  - 寸法変更で面アスペクトが変わった際の中央クロップ自動補正（`needsRecrop`）

### 2. 背景色変更 ＋ 3D 室内プレビュー
- 右ペイン上部に「**シンプル / 部屋**」トグル（両方維持）
- **背景色ピッカー**（プリセット 6 色 ＋ カスタムカラー、シンプルモード時のみ）
- **室内シーン**（実寸 1 単位 = 1m）: テーブル天面の決まった位置に箱を実寸配置（配置は固定）
- `BoxMesh` を `unitScale` prop で「正規化（シンプル）」「実寸 0.001（部屋）」に切替

### 3. 室内の作り込み ＋ ライティング修正 ＋ 展開図の書き出し
- **室内を大幅拡張**（`Room.tsx` / `roomTextures.ts`）: 板張りテーブル・床、ラグ、幅木、窓（枠＋桟＋レースカーテン＋採光）、観葉植物、フロアランプ（点灯）、額装アート、壁掛け時計、本の山、マグカップ。木目・織地・壁は手続き的テクスチャで生成
- **多灯ライティング**: 斜めに差す太陽光（影キャスト・シャドウカメラを絞る）＋ 窓の面光源（`RectAreaLight`）＋ ランプの暖色点光源 ＋ 半球光。`SoftShadows`。露出をモード別に調整
- **「机に箱の影が出ない」を修正**: 太陽光を寝かせて影を可読化 ＋ 天板 `receiveShadow` ＋ `ContactShadows`
- **展開図の書き出し**（`lib/exportNet.ts` / `NetExportMenu.tsx`）: PNG / JPEG / PDF。DOM 非依存で自前 SVG を組み立て

### 4. マグカップの持ち手を縦向きに修正

### 5. 書き出しを「印刷して切れば箱になる」型紙（ダイライン）に作り直し
- 線を細く（アウトライン 0.6mm → カット 0.25mm / 折り 0.2mm）
- **実線＝カット（フラップ外郭の連結）/ 破線＝折り（面同士・面とフラップの境界）** を明確化
- 原寸 100%（`width="○mm"` / PDF ページ = 実寸 mm）、約 300dpi ラスタ、凡例つき
- フラップのはみ出しを吸収する余白を自動計算（`NetLayout` に `flapDepth` 追加）

### 6. Vercel デプロイ
- `git init` → GitHub リポジトリ（`tetsurounagao/Box-Creater`）へ push
- 初回ビルドが `npm run build` ではなく `npm run dev` を実行して失敗 → `vercel.json`（`framework: vite` / `buildCommand` / `outputDirectory`）を追加して解消 → デプロイ成功

### 7. スマホ（モバイル）対応
- `mobile-responsive` ブランチで実装 → Vercel プレビューで確認 → `main` に fast-forward マージ
- 約 600px 未満は「展開図 / 3D」**タブ切替**で片方を全画面（601–900px は縦 2 分割、超は横並び）
- `100dvh` / `viewport-fit=cover` / 横スクロール・オーバースクロール抑止
- **3D モバイル軽量モード**: `SoftShadows` OFF、影・接地影の解像度ダウン、`dpr` 上限 1.5。非表示タブの Canvas は `frameloop="never"` で描画停止
- タッチ対応: ドラッグハンドルの当たり判定拡大、視点ボタンを `<select>` 化、ヒントはタッチ非表示、寸法入力 16px 化（iOS 自動ズーム抑止）、トリミングモーダルの高さ・タップ領域をレスポンシブ化
- `useMediaQuery` フック（`useIsMobile` / `useIsCoarsePointer`）を追加

## 既知の制約・注意点

- **展開図 PDF が実寸で大きい**: 幅 = 2×奥行 + 2×幅。120mm 箱でもページ 464×298mm になり A4/A3 に収まらない → 分割印刷か縮小版が必要
- **three.js バンドルが大きい**（gzip 約 176KB ＋ R3F 約 120KB）。初回ロードがやや重い
- **タブが非アクティブなときの 3D 初期描画**: ブラウザの rAF スロットリングで、操作するまで真っ白に見えることがある（実機の可視タブでは問題なし）
- テストコード・ESLint 未導入
- `Room.tsx` が肥大化（1 ファイル 400 行超）
- `boxStore.ts` に dev 限定の `window.__box` フックが残っている（本番ビルドでは除去される）

## アプリ改善案

### 優先度：高（実用性に直結）

| 案 | 内容 |
|---|---|
| 状態の永続化・共有 | 寸法・モード・背景色を `localStorage` 保存。寸法を URL クエリに載せて共有可能に |

| 画像の入れ方を楽に | 面へのドラッグ&ドロップ、クリップボード貼り付け、「全面に同じ画像」「単色で塗る」 |
